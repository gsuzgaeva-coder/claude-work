# Приёмки Яндекс Маркета

Правила отбора заявок и ловушки — в `knowledge/02_яндекс_маркет_поставки.md`,
прочитайте перед первым запуском.

## Запуск

```bash
python scripts/ym_supplies_export.py
```

Скрипт читает ключи кабинетов из `.env` (образец — `.env.example`), выгружает заявки и
составы, сопоставляет артикулы кабинета с баркодами, подписывает баркоды артикулом и
размером из `data/spravochnik_tovarov.csv` и пишет файл в том же виде, что
`data/ЯМ_приёмки_для_логиста_05-10-2026.xlsx`:

- `out/ЯМ_приёмки_<дата>.xlsx` — свод, приёмки по заявкам, построчно, по баркодам,
  ещё не принятые;
- `out/ym_priemki_lines.csv` — те же строки для загрузки в журнал «Приёмки_МП».

Первая выгрузка идёт около 25 минут (Маркет отдаёт составы медленно). Дальше скрипт
использует кэш `data/cache/` и перечитывает только изменившиеся заявки — минута-две.

## Проверка результата (обязательна)

1. Скрипт сам сверяет сумму строк с итогом каждой заявки и печатает расхождения —
   их должно быть ноль.
2. Строки без баркода и баркоды не из справочника печатаются отдельными списками.
   - Нет баркода (карточку удалили в ЯМ): найди баркод в справочнике по артикулу и
     размеру, впиши в `data/barcode_overrides.csv` и перезапусти.
   - Баркода нет в справочнике (новый товар): добавь строку в
     `data/spravochnik_tovarov.csv` — артикул и размер из кабинета или у фулфилмента.
   Если подставил по предположению — пометка «проверить» остаётся, пока логист не
   подтвердит.
3. «Принято всего» может только расти. Скрипт сам сравнивает с прошлой выгрузкой и
   печатает «ВНИМАНИЕ», если по какой-то ИП итог уменьшился. Тогда не загружай —
   разберись и покажи логисту.

## Загрузка в журнал

В «Приёмки_МП» дописываются только заявки, которых там ещё нет (ключ строки —
`№ заявки ЯМ + баркод`). Уже внесённые строки не переписываются: заявка в статусе
«принята» больше не меняется. После загрузки сверьте сумму «принято» в журнале по
площадке ЯМ с итогом выгрузки и запишите строку в «Журнал_загрузок».

Заявки из листа «Ещё не принято» в журнал не идут. Покажите их логисту списком; если
заявка висит на приёмке больше двух недель — отметьте это отдельно.

## Частые вопросы

- **«Сколько приняли по заявке N?»** — лист «Приёмки по заявкам», поиск по номеру.
- **«Сколько всего отгрузили модели X?»** — лист «По баркодам»; уточните, нужен ли
  один год или всё время.
- **«Фулфилмент отгрузил, а в приёмках нет»** — проверьте отменённые и пересозданные
  заявки (ловушка 2 в базе знаний), затем скилл `sverka`.
