# Как начать работу с агентом

Эта папка — твой агент учёта логистики. В ней его инструкции, знания о нашей
логистике, навыки и рабочий скрипт. Данные и ключи доступа лежат только на твоём
компьютере.

## 1. Установка (один раз, ~10 минут)

1. Распакуй папку `logistics-agent` туда, где она будет жить постоянно, например в
   «Документы». Не в «Загрузки» — оттуда её легко случайно удалить.
2. Открой приложение **Claude** → вкладка **Code** → выбери эту папку как рабочую.
3. Напиши агенту первое сообщение:

   > Привет. Проверь, что на компьютере есть всё для работы, установи недостающее и
   > расскажи, что уже готово и с чего начнём.

   Агент сам проверит Python, поставит нужные библиотеки и всё объяснит. На вопросы
   «разрешить выполнить команду?» можно отвечать «да» — агент перед этим скажет, что
   команда делает.

## 2. Ключи доступа

Ключи кабинетов агент не знает — их вписываешь ты.

1. Скажи агенту «создай .env из примера» — он создаст файл и покажет, какие строки
   заполнить.
2. Яндекс Маркет: кабинет → Настройки → API-ключи. Номера `business_id` и
   `campaign_id` видны в адресной строке кабинета.
3. UPSELLER и UPMARKET: ключ API из их кабинетов — строки для них в том же файле.
4. Ключи вписывай прямо в файл `.env`, **в чат их не отправляй**.
5. Проверка: «Запусти выгрузку приёмок Яндекс Маркета». Первый запуск идёт около
   25 минут, следующие — пару минут. В конце должно быть «Сверка … сошлось».

## 3. Что уже есть

- `data/ЯМ_приёмки_для_логиста_05-10-2026.xlsx` — все фактические приёмки Яндекс
  Маркета по обеим ИП за всё время, сверенные с кабинетами. Начни с листа «Читать
  сначала».
- `data/spravochnik_tovarov.csv` — баркод → артикул и размер (568 баркодов из
  приёмок ЯМ).
- `knowledge/` — обозначения, как устроены поставки Маркета, почему сломался прошлый
  учёт и вариант устройства нового.
- `ЖУРНАЛ_ПРОЕКТА.md` — что сделано и что дальше. Агент ведёт его сам.

## 4. Как с ним работать

Говори обычными словами, что нужно: «хочу вести учёт так-то», «вот выгрузка с
фулфилмента, загрузи», «сверь отгрузки с приёмками за сентябрь», «почему тут минус»,
«вот ссылка на таблицу по ЯМ, посмотри». Файлы выгрузок можно класть в папку
`data/входящие/` или просто перетащить в чат.

Агент всё техническое делает сам и объясняет по-простому. Он ничего не отправляет
фулфилментам и площадкам и не создаёт заявок — он готовит данные и файлы. Структуру
учёта, уже внесённые строки и план он меняет только после твоего «да».

## 5. Чего не делать

- Не пересылать файл `.env` и не вставлять ключи в чат и в таблицы.
- Не хранить таблицы учёта на личном аккаунте Google — только на аккаунте компании.
- Не удалять папки `backups/` и `data/` — там резервные копии и исходные данные.
