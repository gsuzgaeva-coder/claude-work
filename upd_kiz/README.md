# УПД + КИЗ для ЭДО Лайт (Честный знак)

`build_upd.py` объединяет УПД маркетплейса (XML, формат 5.03, windows-1251) с выгрузкой кодов маркировки (xlsx: Заказ | Наименование товара | Киз):

- КИЗ раскладываются по строкам УПД по артикулу (`КодТов` = часть наименования до « | »);
- в УПД передаётся код идентификации без криптохвоста: `01` + GTIN + `21` + серийный номер (31 символ), как в прошлых УПД;
- если количество в строке не совпадает с числом КИЗ, скрипт останавливается с ошибкой;
- второй признак после GUID в `ИдФайл` ставится в `1` (в файле есть маркированные товары);
- блок «Подписант» заменяется на сотрудника по доверенности (`--fio`, `--dolzhn`; `СпосПодтПолном=2` — МЧД, `3` — бумажная) или остаётся как в исходном УПД (`--keep-signer`).

```
pip install openpyxl lxml
python3 build_upd.py --upd input/upd.xml --kiz input/kiz.xlsx --out out \
    --fio "Фамилия Имя Отчество" --dolzhn "Должность" \
    [--mchd-nom <GUID МЧД> --mchd-date ДД.ММ.ГГГГ]
```

Результат лежит в `out/<ИдФайл>.xml`. Его загружают в ЭДО Лайт и подписывают своей КЭП, МЧД при этом должна быть зарегистрирована. Входные и выходные файлы содержат персональные данные, поэтому в git не попадают.
